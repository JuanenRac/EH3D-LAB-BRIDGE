# EH3D-LAB-BRIDGE: not yet

Good ideas that are not in the current version. Writing them here keeps anybody from implementing them early or twice.

| Idea | Why not yet | Revisit when |
|---|---|---|
| Direct control of instruments | Protocols differ widely; file formats come first | the file-based flow works |
| The file formats of real oscilloscopes and network analysers | Only one defined CSV format is read and no sample file of a real instrument has been looked at | a sample file of an instrument is available |
| A tolerance by default | No tolerance number is invented; they are set after the bench has been characterised | the bench has been characterised |
| Calibration records | A calibration claim needs a procedure and a reference that nobody has written | the bench has a calibration procedure |
| A task kind for the server | The server has no kind of task for a measurement yet | the server accepts tasks from the engines |
